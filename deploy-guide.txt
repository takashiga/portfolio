【ファイル構成の概要】
------------------------------------------------------------
ポートフォリオサイト/
├── index.html              ← トップページ（変更不要）
├── css/style.css           ← デザイン
├── js/main.js              ← 動作スクリプト
├── data/
│   ├── profile.json        ← ★自己紹介をここで編集
│   └── apps.json           ← ★アプリ追加はここに記述
├── apps/
│   ├── snake/index.html    ← スネークゲーム
│   └── memory/index.html   ← 神経衰弱
└── deploy-guide.txt        ← この手順書

------------------------------------------------------------
【STEP 1】自己紹介を編集する
------------------------------------------------------------
data/profile.json を開いて以下を編集してください。

  "name"      → 氏名（日本語）
  "nameEn"    → 氏名（英語） ※ナビゲーションに使用
  "title"     → 肩書き（例: ソフトウェアエンジニア）
  "tagline"   → キャッチコピー（1文）
  "bio"       → 自己紹介文（2〜3文程度）
  "skills"    → 技術スタック（配列で記述）
  "links"
    "github"  → あなたの GitHub URL
    "email"   → メールアドレス

------------------------------------------------------------
【STEP 2】アプリを追加する
------------------------------------------------------------
data/apps.json に以下の形式で項目を追加してください。

  {
    "id":          "アプリID（半角英数、重複しないように）",
    "title":       "表示タイトル",
    "description": "説明文（2〜3文）",
    "tags":        ["タグ1", "タグ2"],
    "thumbnail":   "絵文字 or 画像パス",
    "path":        "apps/your-app/index.html",
    "featured":    true
  }

アプリファイルは apps/ フォルダ内にサブフォルダを作って配置します。
例: apps/calculator/index.html

------------------------------------------------------------
【STEP 3】GitHub にプッシュする
------------------------------------------------------------
1. GitHub にリポジトリを作成する
   → https://github.com/new
   → リポジトリ名: portfolio（任意）
   → Public で作成（Static Web Apps の無料プランは Public 推奨）

2. ローカルでコマンドを実行する
   ※ このフォルダ（ポートフォリオサイト/）がルートになります

   cd "C:\Users\takahiro tanaka\OneDrive - 同志社大学\デスクトップ\ポートフォリオ\ポートフォリオサイト"

   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/あなたのユーザー名/portfolio.git
   git push -u origin main

------------------------------------------------------------
【STEP 4】Azure Static Web Apps で公開する
------------------------------------------------------------
1. Azure Portal にログインする
   → https://portal.azure.com

2. 「Static Web Apps」を検索して選択 → 「作成」をクリック

3. 基本設定
   - サブスクリプション: 使用するものを選択
   - リソースグループ: 新規作成 または 既存のものを選択
   - 名前: portfolio（任意）
   - ホスティングプラン: Free（無料）
   - リージョン: East Asia（日本に近い）

4. デプロイの詳細
   - ソース: GitHub
   - 「GitHub でサインイン」してリポジトリを選択
   - 組織: あなたのアカウント
   - リポジトリ: portfolio
   - ブランチ: main
   - ビルドプリセット: HTML（またはカスタム）
   - アプリの場所: /（ルートをそのまま指定）
   - API の場所: （空欄でOK）
   - 出力の場所: （空欄でOK）

5. 「確認と作成」→「作成」をクリック

6. デプロイ完了後、Azure Portal の「概要」に
   表示される URL でサイトが公開されます。
   例: https://ランダム文字.azurestaticapps.net

------------------------------------------------------------
【STEP 5】更新する（2回目以降）
------------------------------------------------------------
ファイルを変更して以下を実行するだけで自動でデプロイされます。

   git add .
   git commit -m "更新内容のメモ"
   git push

GitHub Actions が自動的に Azure へデプロイします。
（Azure Portal で GitHub Actions の連携が設定されます）

------------------------------------------------------------
【よくある確認事項】
------------------------------------------------------------
・ファイルの文字コードは UTF-8 で保存してください
・ファイル名・フォルダ名にスペースや日本語は使用しないでください
  （現状の構成は英語のみなので問題ありません）
・ブラウザで直接 index.html を開くと fetch() がエラーになります
  ローカルで動作確認するには VS Code の Live Server 拡張を使うか、
  以下のコマンドで簡易サーバーを起動してください:
    python -m http.server 8080
  → ブラウザで http://localhost:8080 を開く
